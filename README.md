
 # MoveUp

Projeto desenvolvido em Java para a solução MoveUp, proposta no FIAP Challenge.

## Sobre o projeto

O MoveUp é uma solução voltada à mobilidade urbana sustentável, que busca incentivar práticas de transporte mais sustentáveis por meio de missões, pontos e vouchers.

O projeto foi desenvolvido em Java com integração a banco de dados, utilizando uma estrutura organizada em camadas e padrões trabalhados na disciplina.

## Tecnologias

- Java
- Oracle Database
- JDBC
- IntelliJ IDEA

## Funcionalidades

- Gerenciamento de usuários
- Gerenciamento de missões
- Gerenciamento de transportes
- Gerenciamento de vouchers
- Operações de cadastro, consulta, atualização e exclusão de dados

## Estrutura

- Model — representação das entidades e regras de negócio
- DAO — acesso e operações no banco de dados
- Connection — conexão com o banco de dados
- Test — execução e teste das funcionalidades

## Contexto acadêmico

Projeto desenvolvido para a disciplina Domain Driven Design Using Java, como parte do FIAP Challenge.
